1. 보유 보험 계약 현황 (납입 · 만기 한눈에 보기)

No 보험사 / 상품명 가입연도 / 실손세대 납입 · 만기 · 갱신상태 월 보험료 핵심 역할 관리

2. 전체 보장 합산 요약 (권장 기준치 대비 자동 진단)

체크 해제된 기준치 항목 및 신규 크롤링 자동추가 항목은 합산 가입액이 있는 경우 참고(비활성)로 표시됩니다.

구분 보장 항목 합산 보장액 권장 기준치 진단 결과 증권별 세부 가입 내역

3-1. 부족한 보장 (보완 우선순위)

3-2. 과도·중복 및 리밸런싱 점검

3-3. 연령대별 잔존 보장액 시뮬레이션 (만기 공백 점검)

60세·80세·90세·100세 만기 조건에 따라 은퇴 이후 실제로 남아 있는 보장 금액을 예측합니다.

핵심 보장 항목 현재 유효 보장액 65세 시점 잔존액 85세 시점 잔존액 만기 공백 진단

4. 증권별 세부 담보(특약) 원장

각 담보를 클릭하여 수정·삭제하거나 신규 특약을 추가할 수 있습니다.

🛠️ 맞춤형 보완 설계 시뮬레이터

부족한 담보를 선택하고 가입금액과 만기 조건을 조절하여 예상 보험료와 설계 전후 변화 효과를 시뮬레이션합니다.

최신 무료 모델 간 자동 우회하며, API 한도 초과 시에도 내장 한국어 OCR 엔진이 스캔 PDF와 이미지를 무제한 판독합니다.

Google Apps Script 웹 앱 URL을 연결하면 모든 기기에서 실시간으로 저장·불러오기 됩니다.

💡 가족 공유용 읽기전용 링크 안내

연결 완료 후 가족에게 공유할 때는 주소 뒤에 ?mode=view 를 붙이거나 상단 [백업 / 공유 → 가족 공유용 읽기전용 링크 복사]를 누르세요. (클라우드 주소까지 링크에 자동 포함되어 가족 스마트폰에서도 즉시 최신 데이터가 열립니다.)
